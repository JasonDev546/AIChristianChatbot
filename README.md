# AI Christian Chatbot App
## Chatbot that provides information on four Christian denominations (Eartern Orthodoxy, Catholicism, Protestantism, and Jehovah's Witness) in an engaging and user-friendly format.

## Project Overview
The **AI Christian Chatbot** is a Python-based, command-line application that integrates the OpenAI API to provide interactive, AI-generated responses to questions about Christian religious beliefs, doctrines, and practices. 

The application allows users to select from four Christian religious traditions: Catholicism, Protestantism, Jehovah's Witness, and Eastern Orthodoxy. Each tradition offers two predefined subtopics, allowing users to explore specific religious teachings through interactive conversations. 

The chatbot uses system instructions to guide AI-generated responses toward the selected denomination and subtopic while encouraging respectful, nonjudgemental communication. It also maintains a conversation history to preserve context during interactions. 

Users can switch between denominations and subtopics without restarting the application by entering 999, which clears the previous conversation history and returns them to the topic selection menu. They can also terminate the application by entering ```exit```.

Additionally, the application presents important disclaimers regarding the limitations of AI-generated information, the educational purpose of the chatbot, and the importance of protecting personal and sensitive information. 

The project demonstrates the practical application of Python object-oriented programming, OpenAI API integration, conditional statements, nested loops, input validation, exception handling, and conversation history management to develop an interactive educational chatbot.

## Features

* **OpenAI API Integration:** Connects to the OpenAI API to generate responses to users' questions about Christian religious beliefs, doctrines, and practices by using an API key generated by OpenAI.
* **Christian Denomination Selection:** Allows users to select one of four Christian religious traditions: Catholicism, Protestantism, Jehovah's Witness, or Eastern Orthodoxy.
* **Subtopic Selection:** Provides two predefined subtopics for each religious tradition, allowing users to explore specific religious teachings.
* **Topic-Specific AI Responses:** Uses system instructions to guide the chatbot toward answering questions related to the selected denomination and subtopic while promoting respectful and nonjudgemental communication.
* **Conversation History Management:** Maintains previous user messages and AI-generated responses to preserve conversational context within the selected subtopic.
* **Dynamic Topic Switching:** Allows users to change denominations and subtopics during execution by entering 999, automatically clearing the previous conversation history without restarting the application.
* **User Input Validation:** Validates denomination and subtopic selections, prompting users to enter a valid option when an invalid selection is detected.
* **API Error Handling:** Uses exception handling to capture and display errors encountered during OpenAI API requests.
* **Processing Status Indicator:** Displays a temporary ```Processing...``` message while waiting for the AI-generated response.
* **Application Exit Command:** Allows users to terminate the chatbot by entering exit.
* **Ethical and Privacy Disclaimers:** Presents important clarifications about AI limitations, educational purposes, and sensitive information before allowing users to interact with the chatbot.
* **Object-Oriented Design:** Orgganizes the application into separate Python classes for API communication and chatbot functionality, improving code organization and maintainability.

## Prerequisites:
Before installing and running the AI Christian Chatbot, ensure that you have the following: 
* **Python 3.9 or later:** Required to execute the Python application and install the OpenAI Python SDK (For security purposes, it's recommended that you have the current version)
* **pip (Python Package Manager):** Required to install the ```openai``` Python package and its dependencies.
* **OpenAI Account:** An account on the OpenAI Platform is required to access the OpenAI API.
* **OpenAI API Key:** A valid API key generated through the [OpenAI API Keys](https://platform.openai.com/api-keys) page is required to authenticate API requests.
* **Active OpenAI API Billing:** An API account with active billing and sufficient credits is required to process requests. API usage may incur charges.
* **Internet Connection:** Required to communicate with the OpenAI API and receive AI-generated responses.
* **Terminal or Command-Line Interface:** Required to execute the Python application and interact with the chatbot.

## Installation

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/ComeG3tSome/AIChristianChatbot
   cd AIChristianChatbot
   ```
2. Install the necessary Python packages required for the script to execute successfully
   ```
       pip install openai
   ```
3. Generate an OpenAI API key through the [OpenAI Platform](https://platform.openai.com/api-keys) and ensure that your API billing account is active.
4. Configure your OpenAI API key as an environment variable:
   
   **Windows (Powershell):**
     ```$env:OPENAI_API_KEY = "YOUR_API_KEY"```
   
   **Windows (Command Prompt):**
     ```set OPENAI_API_KEY=YOUR_API_KEY```
   
   ***macOS/Linux:**
     ```export OPENAI_API_KEY="YOUR_API_KEY"```
   
6. Ensure that the Python script retrieves the API key from the environment variable:
   ```
   import os

   api_key = os.environ["OPENAI_API_KEY"]
7. Run the application:
   
   python AICHRISTIANCHATBOT.py
